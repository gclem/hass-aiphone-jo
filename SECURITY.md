# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them
privately through GitHub's
[private vulnerability reporting](https://github.com/gclem/hass-aiphone-jo/security/advisories/new).

Include a description of the issue, the affected version and steps to
reproduce. Do not include credentials, certificates or identifiers of your
installation.

## Supported versions

Only the latest release receives security fixes.
